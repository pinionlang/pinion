# Pinion 적합성 예제

[DESIGN.md](../../docs/DESIGN.md) 3장의 규칙마다 **정상 코드, 컴파일 에러, 경계 사례**를 작은 예제로 둔다.

- 컴파일러의 적합성 테스트로 쓴다. 골든 테스트 하네스가 이 파일들을 읽는다.
- AI용 핵심 가이드(`spec/GUIDE.md`)와 레퍼런스(`spec/REFERENCE.md`)의 예제 원본으로 쓴다.
- 아직 컴파일러가 없으므로, 지금은 **명세를 검토하는 용도**다.
- `//#`와 `//~`는 **테스트 하네스만 읽는 표시**다. 컴파일러에게는 일반 주석이며 컴파일 동작을 바꾸지 않는다(DESIGN.md 3.19).
- 예제에 나오는 표준 라이브러리 이름(`fs.read`, `fs.fake`, `json.decode`, `JsonError.kind` 등)은 초안이다. 표준 라이브러리 명세에서 확정한다.

## 파일 형식

한 파일에 여러 사례를 넣는다. 각 사례는 독립된 프로그램이다.

```pinion
//# case: data-list-of-class
//# expect: error
class Counter { mut n: Int = 0 }

data Snapshot {
  pub counters: List<Counter>   //~ E1401
}
```

| 지시문 | 뜻 |
|---|---|
| `//# case: 이름` | 사례 시작. 이름은 파일 안에서 유일해야 한다 |
| `//# expect: ok` | 컴파일 통과. 진단이 하나도 없어야 한다 |
| `//# expect: error` | 컴파일 실패. `//~` 표시와 실제 진단이 정확히 일치해야 한다 |
| `//# expect: warning` | 컴파일 통과. 경고는 `//~` 표시와 일치해야 한다 |
| `//# expect: run` | 컴파일하고 `main`을 실행한다. 아래 `stdout`, `exit`과 비교한다 |
| `//# expect: abort R0102` | 실행 중 해당 결함으로 중단돼야 한다(종료 코드 70) |
| `//# expect: tests` | `pinion test`를 실행한다. 아래 `test` 줄과 결과를 비교한다 |
| `//# stdout: 텍스트` | 표준 출력 한 줄. 여러 번 쓸 수 있다 |
| `//# exit: N` | 종료 코드. 생략하면 아래 기본값을 쓴다. 쓴 경우 기본값과 같아야 한다(다르면 사례 자체가 잘못된 것으로 본다). 단 `run`은 기본값을 덮어쓸 수 있다 |
| `//# test: 이름 -> 결과` | `passed`, `failed T0001`, `aborted R0102`, `timeout T0003` |
| `//# file: 경로` | 다음 줄부터 해당 파일의 내용이 시작된다. 소스 파일(`src/...`)뿐 아니라 테스트가 실제로 읽을 데이터 파일도 만들 수 있다. 경로는 임시 작업 디렉터리 기준이다. 이 지시문을 쓰는 사례는 모든 코드를 파일 안에 둔다 |
| `... //~ 코드` | 이 줄에서 해당 진단이 나와야 한다. 한 줄에 여러 개를 쓸 수 있다 |

### 종료 코드 기본값

| expect | 기본 종료 코드 |
|---|---|
| `ok`, `warning` | 0 (`pinion check`) |
| `error` | 1 (`pinion check`) |
| `run` | 0. `main`이 `Err`를 돌려주는 사례처럼 다른 값이면 `//# exit`로 덮어쓴다 |
| `abort Rxxxx` | **70으로 고정** |
| `tests` | `//# test` 줄이 모두 `passed`이면 0, 하나라도 아니면 1 |

### 실행 환경

하네스는 사례마다 다음 환경을 보장한다. 표준 효과를 통한 외부 입력을 통제하기 위해서다. 실행 시간, 운영체제·플랫폼 차이까지 없애지는 않는다.

- 새로 만든 **빈 임시 디렉터리**를 작업 디렉터리로 쓴다. `//# file`로 만든 파일만 그 안에 있다
- 환경변수는 `PATH`와 하네스가 정한 값만 남기고 비운다
- 명령줄 인자는 없다
- `tests` 사례의 테스트는 DESIGN.md 3.13 규칙 9의 기본 가짜 효과 위에서 돈다
