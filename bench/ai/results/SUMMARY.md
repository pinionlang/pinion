# CRUD 백엔드 AI 작성 비용 벤치마크

같은 명세(`crud/SPEC.md`)를 언어마다 새 에이전트(같은 모델, 언어 한 줄만 다른 같은 지시문)에게 구현시키고 숨겨진 블랙박스 테스트 74개로 채점했다. 언어마다 3회 반복.

## 최종 (3회 평균, 2026-11-20)

| 언어 | 테스트 (3회) | 소스 토큰 | 에이전트 총 토큰 | 도구 호출 | 시간 |
|---|---|---:|---:|---:|---:|
| Python (FastAPI) | 74/74 ×3 | 1,243 | 29,844 | 3.0 | 0.70분 |
| TypeScript (node:http) | 74/74 ×3 | 1,474 | 30,503 | 3.3 | 0.77분 |
| Go (net/http) | 74/74 ×3 | 2,057 | 31,192 | 3.3 | 0.83분 |
| **Pinion v3** | **74/74 ×3** | **1,302** | **36,785** | **5.0** | **0.97분** |

## Pinion 개선 이력 (각 1회)

| 버전 | 바뀐 것 | 소스 토큰 | 에이전트 총 토큰 |
|---|---|---:|---:|
| v1 | std/http만 있음 (JSON 파서를 직접 작성) | 3,724 | 53,094 |
| v2 | `json.Json` 동적 값 | 1,578 | 41,197 |
| v3 | 참조 카드(2.9k 토큰) + 검증 헬퍼 + Result 핸들러 | 1,302 (평균) | 36,785 (평균) |

- 소스 토큰: tiktoken cl100k. 에이전트 총 토큰: 하위 에이전트 사용량.
- 회차별 원자료: `rounds/r{1,2,3}/`, `results/r{1,2,3}/`, v1·v2: `archive/`.
- r2·r3의 Pinion은 처음에 `server did not accept connections`로 0점이었다. 원인은 `pinion build -o`가 기존 실행 파일을 제자리에서 덮어써 macOS가 새 바이너리를 SIGKILL한 컴파일러 버그였다(임시 파일 후 rename으로 수정). 소스는 그대로 두고 다시 채점했다.
